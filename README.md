Skyline Courier is an original 3D bush-pilot flight game: fly a battered little courier plane over a seeded island archipelago, thread glowing rings, hop between island strips, and run the mail home — while fuel and damage turn every sortie into a decision. Three missions with different goals (Ring Rush, Island Hop, Courier Run), arcade physics with stalls and flaps, a lit HUD with speed, altitude, heading, compass, artificial horizon, fuel and damage gauges, and a smooth chase camera. Built with Three.js, all art and sound generated in code, no network at runtime.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Pick a mission (keys 1/2/3 or click), fly with arrow keys / WASD, Shift/Ctrl for throttle, F for flaps, P to pause, R to restart, M to mute. Screenshot presets: `?shot=start|flight|approach|complete`.
